# Отчёт о frontend-тестировании JetFood

> Этот отчёт фиксирует прогон 23.11.2026 до перехода на JetPoints. Результаты новой
> программы от 25.11.2026 находятся в JETPOINTS_IMPLEMENTATION.txt и test-results/jetpoints-frontend.json.

Дата последнего полного запуска: **2026-11-23T18:45:35+05:00**, Asia/Qyzylorda (UTC+05:00).

Среда: Windows, PowerShell, Node 24.13.1, Angular 21.2.26 standalone,
TypeScript 5.9.3, Vitest 4.1.12 / jsdom через Angular unit-test builder.
Backend: Python 3.14.3, Django 5.2.13, DRF 3.14.0, SQLite.

## Команды и итог

Из `frontend`:

```powershell
npm.cmd test -- --watch=false --reporters=json --output-file=../test-results/frontend-all.json
npm.cmd test -- --watch=false --include=src/app/commerce.acceptance.spec.ts --reporters=json --output-file=../test-results/frontend-30.json
npm.cmd run build
```

Последний полный прогон: **153/153 PASS**, включая ровно 30 сценариев ниже.
`frontend-30.json` — выделенная часть последнего полного машинного отчёта с исходными assertion results;
изолированный запуск этих 30 также выполнялся во время работы.
Production build: **PASS**, initial bundle около 648 kB. Существующие warning-бюджеты
500 kB для initial и 4 kB для части CSS превышены; жёсткие бюджеты не повышались.

Backend из корня:

```powershell
py manage.py check
py manage.py migrate --check
py manage.py makemigrations --check --dry-run
py manage.py test --settings=backend.test_settings --noinput
```

**186 backend-теста PASS**, system check без замечаний, расхождений моделей/миграций нет.
Миграции применены к локальной базе после backup. Тестовый settings использует быстрый
хешер и повышенную общую квоту API для изоляции скоростного прогона; рабочие настройки
аутентификации и лимитов не меняются. Специальный лимит чата сохраняется.

## Область доказательств

Все 30 frontend-сценариев — component/integration-тесты реальных standalone-компонентов
и шаблонов с **явными mock API**. Платёжный переход перехватывает spy: браузер не
посещает банк. T30 проходит через реальные Dashboard/PaymentResult, но использует
mock ответ подтверждения; это **не реальный sandbox и не браузерный E2E**.
Арифметика, подпись, права доступа, повторные события, конкуренция и возвраты отдельно
проверяются backend-тестами, а не доказываются mock ответами интерфейса.

## Дополнительные проверки и ограничения

| Проверка | Результат | Основание |
|---|---|---|
| Backend: собственные/чужие чаты, заказы, кошельки, платежи | PASS | Реальные Django API/БД в изолированных тестах |
| Backend: цена с сервера, скидки, снимки и резерв | PASS | Подмена браузерной суммы не влияет; цены перечитываются |
| Подпись и неподписанный ответ провайдера | PASS | Официальный контрольный вектор подписи, неверный callback и unsigned XML отвергнуты |
| Повторные/параллельные платёжные события | PASS | SQLite, один spend и один набор событий |
| Два одновременных списания одного баланса | PASS | Только один заказ резервирует доступные бонусы |
| Начисление в любом порядке оплаты/доставки, возвраты и debt | PASS | Реальные транзакции/журнал; частичный и полный возврат |
| Сохранность старых записей при миграции | PASS | Сравнение прежних колонок с SQLite backup |
| Настоящая Ollama: RU баланс/доставка | PASS | Реальный ответ с 1234,50 KZT, доставка исключена |
| Настоящая Ollama: EN чужой заказ | PASS | Отказ; чужие данные не передавались модели |
| Настоящая Ollama: KK качество ответа | FAIL | Ответ неполный и неестественный; не назван лимит |
| Настоящая Ollama: сохранение трёх историй | PASS | После каждого запроса GET вернул приветствие, вопрос и ответ |
| Freedom Pay sandbox / реальные webhook от провайдера | BLOCKED | Нет тестовых merchant credentials/публичного callback |
| Реальные списания | NOT RUN | Не выполнялись по условию задачи |
| Ручной desktop/mobile и браузерный E2E | NOT RUN | Выполнены DOM/component-тесты; ручного визуального прогона не было |
| PostgreSQL / несколько серверов под нагрузкой | NOT RUN | Доступна SQLite; отдельная приёмка окружения production |

Статусы дополнительных проверок не входят в сумму ровно 30 frontend-сценариев.
Прохождение frontend-мока не означает, что Freedom Pay был подключён к банку.

тестовые ошибки обнаружения изменений Angular, тип ключа идемпотентности и влияние
