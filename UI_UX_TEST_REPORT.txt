Date: 2026-11-09

Scope
Twenty acceptance checks cover role workflows, checkout/payment, delivery
route mapping, notifications, serializer contracts, language, and error
feedback. Automated status refers to backend or Angular tests; external map
service and visual checks are explicitly marked manual because a successful
unit test cannot verify public tile/router availability or real-device layout.

Manual check procedure for item 20
1. Start Django and Angular using HOW_TO_RUN.txt.
2. Log in with a manager/courier account created by
   python manage.py create_demo_roles.
3. Open an assigned order, plan A and B points, and confirm the route line,
   distance, estimated time, and OpenStreetMap directions link.
4. Repeat with a narrow/mobile viewport and test marker drag, map attribution,
   notification refresh, and payment history.
5. Repeat with network access disabled; verify the UI reports that external
   route geometry is unavailable while saved points remain visible.

Limits
This report is an acceptance checklist, not evidence that the remote OSRM
service is always available. The project does not provide live courier GPS,
traffic-aware ETAs, email/SMS/push notifications, or actual bank processing.
