Catalog price answers — 2026-11-27, Asia/Qyzylorda

Root cause: the language model was still composing prices from a mixed menu.
Observed chat example: a doner in Bahandi was assigned the 750 KZT fries price.

Fix: menu/price queries now use an explicit, read-only catalog tool. It selects
the restaurant and food type/modifiers and formats Decimal values from MenuItem.
An explicitly named burger is not substituted with a cheeseburger. Unknown food
and unloaded menus return clarification/missing-data messages, not another price.
The result is identified as source=catalog and displayed as JetFood catalog data.
It is not presented as generated AI text. General support still uses Ollama/FAQ.
Historical messages remain unchanged. Catalog price data is read on each request.

  chicken cheeseburger 1700.00 KZT, matching stored menu records.
These are app database prices, not an independently verified external live menu.

changes a dish price and verifies the next reply contains the new Decimal value,

Russian, English, Kazakh, unavailable dishes, unknown restaurant and empty menus
